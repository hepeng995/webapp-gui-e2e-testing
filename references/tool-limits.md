# 浏览器自动化能力边界（tool-limits）

基于 ZCode 内置浏览器实测归纳。本 skill 仅使用 ZCode 内置浏览器执行测试（SKILL.md §5 第 10 条）；内置浏览器自带的使用规则优先于本文件；工具能力升级后应修订本清单。

## 1. 已知能力边界

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 点击 / 输入 / 滚动 / 键盘 | 可用 | 基于可访问性树或坐标定位 |
| 截图 / DOM 只读读取 | 可用 | 证据主通道 |
| console 监听 / 网络观察 | 视工具而定 | 开工预检确认（environment.md §3 第 7 项） |
| 文件上传（file chooser） | 常受限 | 系统文件选择器可能无法打开 |
| 拖拽（DND 库，如 React DND） | 常受限 | 合成拖拽可能不触发放置；键盘替代（Tab/空格）也可能不生效 |
| 特殊点击热区 | 易失败 | 图形化元素（菱形标记、画布节点、SVG 图标）坐标点击可能不命中 |
| 剪贴板粘贴 | 部分可用 | 富文本粘贴图片（Ctrl+V 上传）实测可行，可作为上传降级通道 |
| 系统级弹窗（alert/confirm 原生对话框） | 视工具而定 | 预检确认能否驱动 |
| 文件下载（导出） | 视工具而定 | 预检确认下载落盘位置；导出类用例验证方式见 §5 |
| 新窗口（window.open / target=_blank） | 视工具而定 | 预检确认；可能需枚举标签页后接管新窗口 |
| beforeunload 离开拦截 | 视工具而定 | 系统级确认框可能无法驱动 |
| HTTP Basic Auth / 401 认证弹窗 | 视工具而定 | 无法驱动时走"用户手动登录后接管会话"通道（environment.md §2） |
| 网络节流 / 离线模拟 | 视工具而定 | EXC 异常类本地环境优先停后端；工具支持离线/节流模拟时可用 |
| 打印对话框（window.print） | 常受限 | 系统级对话框，标 BLOCKED-tool |

## 2. 处置协议

遇到工具无法完成的操作时，按顺序执行：

1. **识别**：换一种定位/操作方式各试一次（共 3 次上限，见 execution-loop §4）后仍失败 → 判定为能力边界而非页面 bug（区分证据：人工逻辑上元素应存在且可操作）。
2. **标记**：该测试点标 `BLOCKED-tool`，记录已尝试的方式、现象、判定依据。
3. **降级**：仅当降级不改变被测语义时使用。例：file chooser 上传 → 改测粘贴上传（但要在结果中注明"file chooser 通道未验证"）；拖拽排序 → 记 BLOCKED，不许用接口调用替代 UI 拖拽后宣称通过。
4. **禁止**：
   - 禁止伪造成功或含糊其辞（"应该可以了"）；
   - 禁止注入 JS 派发事件/改状态绕过；
   - 禁止为绕过能力边界引入外部浏览器或第三方自动化工具（本 skill 仅用 ZCode 内置浏览器，SKILL.md §5 第 10 条）；
   - 禁止把 `BLOCKED-tool` 混入 FAIL 统计——它不是产品缺陷，是验证通道缺失，但**也不算通过**。

## 3. 报告要求

执行报告单列"工具受限明细"：受影响用例清单、受限能力、对覆盖度的影响、建议的人工验证/替代方案（如 Playwright 专项补齐深交互、真实浏览器会话回归文件链路）。历史教训：文件上传链路全部 BLOCKED 导致一批依赖用例连锁未执行——识别到能力边界后应尽早汇总受影响面，向用户说明，而不是逐条撞墙。

## 4. 深交互专项建议

拖拽嵌套、画布操作、快捷键序列等深交互在会话浏览器下不可靠时，该部分标注"专项待补"，并在报告中建议开发侧后续以 Playwright 专项补齐（鼠标序列/焦点管理可控）；**本轮不通过编写脚本来替代验证**（SKILL.md §5 第 9 条：验证一律浏览器交互式执行）。

## 5. 导出文件验证（导出类用例的验证通道）

导出（CSV/Excel/PDF）类用例不能只断言"下载已触发"，按下列通道验证：

1. **落盘确认**：预检时实测一次小文件下载，确认 ZCode 内置浏览器的下载落盘目录；用"文件存在 + 文件名符合 + 大小 > 0"断言下载完成；
2. **内容校验**：CSV/文本用脚本（Python/Node）读取，断言行数与关键列值（与页面列表口径对比）；Excel/PDF 至少断言可解析、行数/页数与预期同量级；
3. **工具不支持下载落盘观察时**：标 `BLOCKED-tool`，建议人工验证或 Playwright 专项（下载事件可编程断言）；禁止"点了按钮就算通过"。

## 1. 被测对象层级树（L1 模块 → L2 页面 → L3 功能区 → L4 元素，每一级都必须有正确预期效果与来源）

> **预期来源规则**（逐级适用，禁止无来源的"想当然"）：
> ① 文档明确写了 → 预期=文档描述，标注来源章节；
> ② 文档缺失/含糊但代码行为明确 → 预期=代码实际行为，标"依据代码"；与文档矛盾时同时登记"文档差异"；
> ③ 都无法唯一确定（含纯 URL 黑盒）→ 先取黑盒预期来源：页面自身声明 / 平台常识惯例 / 全站一致性（标"依据声明/惯例/一致性"）；仍定不了再标 `待确认` 自动裁决（建议候选 → 代码行为 → 惯例默认），标注"自动裁决：<依据>"留痕，用户可事后纠正；
> ④ 用户纠正后 → 预期回填为"用户 <日期>"，受影响用例重测；无法稳定观察预期的用例结论记"行为观察"，不判 FAIL。
>
> L4 适用类型：F 功能 / U UI-UX / C 兼容 / P 性能 / S 安全 / A 接口 / D 数据 / E 异常 / R 回归 / Us 易用性。模块码 = `<L1>-<L2>` 缩写，用例编号 `TC-<类型码>-<L1>-<L2>-<NNN>`。
